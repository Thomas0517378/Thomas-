# 抚艺工坊项目与财务驾驶舱

双击 `index.html` 即可在浏览器中打开，无需安装依赖或联网。

网站页面包括：

- 项目介绍：7 张活动照片每 5 秒轮播，支持暂停、前后切换、圆点选图、方向键与触屏滑动；自动播放在鼠标悬停、网页切入后台或切换页面时停止，在减少动态效果偏好下默认暂停。
- 财务总览：修正后的五年利润表、利润率趋势与第5年利润推导。
- 收入结构：首末年收入构成图、年份切换、销售单量和单均毛利公式。
- 成本与费用：收入/成本/费用对比、五年人力和费用预测。
- 利润与现金：修正现金流量表、营运资金公式、现金趋势和回收结论。
- 风险防范：人力成本敏感性、70%/85%/100% 用户规模情景切换、现金与营运资金风险。

数据来源为《财务数据修正说明与五年预测表（数据公式版）》；主表使用文档表2、表3，金额默认单位为万元，保留一位小数。所有财务序列集中在 `finance-data.js`，图表和表格共享该数据源，计算公式附在对应内容旁。

核心结论：融资计划 28 万元（20 + 8）；五年净利润为 −7.4、−8.4、2.5、21.6、48.9 万元；期末现金为 3.3、1.0、0.4、17.1、59.2 万元；第3年微利、第4年实质盈利；静态回收期按文档结论约4.9年。

文档未完整披露的年度收入分项和费用细项不作额外拆分。营运资金舍入差异、人力敏感性表与主表的口径差异，已在对应页面及数据口径说明中标明。

照片位于 `assets/activities/`，网页副本已缩放、压缩，采用完整展示方式；原始照片未修改。网站无外部图表、字体或图片依赖，可离线打开，也可部署至 GitHub Pages。

验证：对照原始 .doc 核验13行主表数据；五年利润、经营现金流及期末现金全部勾稽一致；浏览器检查涵盖6页、轮播、情景切换、弹窗与1440/390/320像素布局，未出现 JavaScript 运行错误。
